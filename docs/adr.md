# Architecture Decision Record

## 23/09/2026

Décision : choix du front-end = Je choisi React Router en mode framework

Pourquoi :

- React est très utilisé de nos jours, donc bien maintenu et documenté
- React Router permet de gérer les routes
- React Router en mode framework car "are too new to have an opinion" et "just want to build something with React" (cf https://reactrouter.com/start/modes)
